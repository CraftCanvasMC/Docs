Canvas' development team consists of, at the time of writing, 4 developers and 2 advisors. We all have a lot of things we
do IRL and have limited time to work on Canvas and projects sometimes. This is also a hobby of ours that we do as friends,
so supporting multiple Minecraft versions is a bit difficult.

We follow a generally simple LTS policy, where we only will support the current latest Minecraft version Canvas provides,
and the previous major release version Canvas provides only for backporting fixes. At the time of writing, 26.2 stable
builds have just released, which means this would be our support scope until 26.3 drops:

- Support 26.2 fully, all new features and fixes end up here
- 26.1.2 will be supported only for backporting important fixes until 26.3 Canvas builds drop

This is primarily decided because lots of our users lag behind a version, so we want to offer support for them still,
without making them feel like they are on a time crunch. While it's always important to get on the latest version of Canvas,
sometimes it's harder to do so for various reasons like plugins or something. This policy is meant to try and help servers
more and benefit them so they can still receive support and fixes from our team long-term.
